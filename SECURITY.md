# Security policy

## Reporting a vulnerability

Do not report security problems in public issues. Use GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**.

Include the affected version and platform, the impact, and steps or a file
that reproduces it. You will receive an acknowledgement, and a fix will be
coordinated with you before details are made public.

## Supported versions

Fixes are made against the latest release and the `main` branch. Older
releases are not patched.

## Scope

In scope: the GLCAD application and libraries in this repository, including
file import (DWG, DXF, DGN, STEP, PDF and others), document storage, the
session protocol and the assistant's network tools.

Out of scope: vulnerabilities in third-party AI servers, web sites or services
that a user connects GLCAD to, and issues that require an already-compromised
device.
