Support

For help with GLCAD, bug reports and feature requests, open an issue on GitHub:

GLCAD issues on GitHub

When reporting a problem

  • Your device, operating system version and GLCAD version (shown in About).
  • What you did, what you expected and what happened instead.
  • A screenshot or a drawing that shows the problem, if you have the right to share it publicly. GitHub issues are public, so remove anything confidential first.

Purchases

Refunds and billing for App Store purchases are handled by Apple. Visit reportaproblem.apple.com.

Security issues

Report security problems privately using the repository's Security tab, not in a public issue.
